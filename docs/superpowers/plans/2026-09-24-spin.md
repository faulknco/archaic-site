# Spin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `archaic.ie/lab/spin`, a full-screen two-tone live 2D Ising model where page scroll is temperature, reusing the existing ising-rs WebAssembly build unchanged.

**Architecture:** One self-contained Astro page owns a fixed full-viewport canvas and a tall scroll track. A Web Worker runs the ising-rs WASM (256×256 square lattice, Metropolis sweeps) in a pull model: the page requests a tick with the current temperature on each animation frame, the worker replies with the spin buffer, the page paints it with Canvas 2D. A tiny pure module maps scroll fraction to temperature and is the only unit-tested code; everything visual is verified with a Playwright script.

**Tech Stack:** Astro 7 (static), vanilla ES modules, Canvas 2D, Web Worker, wasm-bindgen output from ising-rs, Node `node:test` for the pure module, Playwright (devDependency) for the browser check.

**Spec:** `docs/superpowers/specs/2026-09-24-spin-design.md`

## Global Constraints

- No numbers on the page (site rule): no temperature readouts, no counts, no years. The filename `archaic-spin.png` has none.
- Pages are self-contained `.astro` files with inline `<style>` and inline `<script>`; no shared layout, no components.
- Cinzel is not used on this page; the text is Space Grotesk. If Cinzel is ever used it must be uppercase in HTML and CSS.
- Palette: spin up `#e8e4d8`, spin down `#060606`, text `#686868`, CTA `#4a4a4a` → `#888` on hover. Page background `#060606`.
- Lattice: `n = 256`, geometry `0` (Square2D), `j = 1.0`, `h = 0.0`, Metropolis only (`step`, never `step_wolff`).
- Scroll→T control points exactly: `(0,5.0) (0.25,3.0) (0.45,2.45) (0.55,2.10) (0.75,1.5) (1,0.6)`.
- Idle drift after 15 s without input, ≈36 px/s, off under `prefers-reduced-motion`; reduced motion also caps sweeps at 1 per tick.
- CSP: add `'wasm-unsafe-eval'` to `script-src` and add `worker-src 'self'`. No new origins.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Work on branch `lab/spin`; never push to `main` directly.
- Node ≥ 22.12. Run `npm run build` before every commit that touches `src/` or `public/`.

`public/lab/spin/tmap.js`:

```js
// Scroll fraction (0 = top, 1 = bottom) → Ising temperature (J/k_B units).
// Piecewise-linear through control points chosen so the middle of the
// scroll range straddles the 2D square-lattice critical point (2.269).
export const CONTROL_POINTS = [
  [0.0, 5.0],
  [0.25, 3.0],
  [0.45, 2.45],
  [0.55, 2.10],
  [0.75, 1.5],
  [1.0, 0.6],
];

export function temperatureFor(s) {
  if (!(s > 0)) return CONTROL_POINTS[0][1];            // NaN or <= 0
  if (s >= 1) return CONTROL_POINTS[CONTROL_POINTS.length - 1][1];
  for (let i = 1; i < CONTROL_POINTS.length; i++) {
    const [s0, t0] = CONTROL_POINTS[i - 1];
    const [s1, t1] = CONTROL_POINTS[i];
    if (s <= s1) return t0 + ((s - s0) / (s1 - s0)) * (t1 - t0);
  }
  return CONTROL_POINTS[CONTROL_POINTS.length - 1][1];
}
```

**Files:**

**Interfaces:**
- Consumes: `/lab/spin/ising.js` (Task 1).
- Produces the message protocol used by Task 4:

  - main → worker `{ type: 'tick', T: number }`
  - worker → main `{ type: 'ready', n: number }`
  - worker → main `{ type: 'frame', spins: ArrayBuffer }` (Int8Array of length n·n, values ±1, transferred)
  - worker → main `{ type: 'error', message: string }`

- [ ] **Step 1: Write the worker**

`public/lab/spin/worker.js`:

```js
// Simulation worker for /lab/spin. Pull model: the page sends one 'tick'
// per animation frame with the current temperature; we run as many
// Metropolis sweeps as fit in the budget and post the spin buffer back.
import init, { IsingWasm } from './ising.js';

const BUDGET_MS = 12;
let sim = null;
let n = 0;
let memory = null;
let maxSweeps = 4;

function spinsView() {
  // Zero-copy view into WASM memory; must be re-created if memory grows.
  return new Int8Array(memory.buffer, sim.spins_ptr(), n * n);
}

self.onmessage = async (e) => {
  const msg = e.data;
  try {
    if (msg.type === 'init') {
      const out = await init();
      memory = out.memory;
      n = msg.n;
      maxSweeps = msg.maxSweeps ?? 4;
      sim = new IsingWasm(n, 0, 1.0, 0.0, BigInt(msg.seed >>> 0));
      sim.randomise();
      self.postMessage({ type: 'ready', n });
      return;
    }
    if (msg.type === 'tick') {
      if (!sim) return;
      const start = performance.now();
      let sweeps = 0;
      do {
        sim.step(msg.T);
        sweeps++;
      } while (sweeps < maxSweeps && performance.now() - start < BUDGET_MS);
      const copy = new Int8Array(spinsView()); // copy out of WASM memory
      self.postMessage({ type: 'frame', spins: copy.buffer }, [copy.buffer]);
    }
  } catch (err) {
    self.postMessage({ type: 'error', message: String(err && err.message || err) });
  }
};
```

```astro
        if (!last) return null;
        let up = 0, agree = 0;
        for (let y = 0; y < N; y++) for (let x = 0; x < N; x++) {
          const s = last[y * N + x];
          if (s > 0) up++;
          const r = last[y * N + ((x + 1) % N)], d = last[((y + 1) % N) * N + x];
          if (r === s) agree++; if (d === s) agree++;
        }
        return { upFraction: up / (N * N), agreement: agree / (2 * N * N) };
      },
    };
  </script>
</body>
</html>
```

```js
// Verifies /lab/spin behaves like an Ising model and loads cleanly.
// Usage: node scripts/qa-spin.mjs [baseUrl]   (default http://localhost:4321)
// Serve first, e.g. `npm run preview` (port 4321) or `npm run build && npx serve dist`.
import { chromium } from 'playwright';

const base = (process.argv[2] || 'http://localhost:4321').replace(/\/$/, '');
const fail = (m) => { console.error('FAIL:', m); process.exitCode = 1; };
const ok = (m) => console.log('ok  :', m);

const browser = await chromium.launch();
const page = await browser.newPage({ viewport: { width: 1280, height: 900 } });
const consoleErrors = [];
page.on('console', (m) => { if (m.type() === 'error') consoleErrors.push(m.text()); });
const wasm = page.waitForResponse((r) => r.url().endsWith('/lab/spin/ising_bg.wasm'));

await page.goto(`${base}/lab/spin/`, { waitUntil: 'domcontentloaded' });
const wasmStatus = (await wasm).status();
wasmStatus === 200 ? ok('wasm served 200') : fail(`wasm status ${wasmStatus}`);

await page.waitForFunction(() => window.__spin && window.__spin.frames > 30, null, { timeout: 20000 });
ok('frames flowing');

const top = await page.evaluate(() => window.__spin.sample());
top.upFraction > 0.4 && top.upFraction < 0.6 ? ok(`top upFraction ${top.upFraction.toFixed(3)}`) : fail(`top upFraction ${top.upFraction}`);
top.agreement < 0.7 ? ok(`top agreement ${top.agreement.toFixed(3)} (noise)`) : fail(`top agreement ${top.agreement}`);

await page.evaluate(() => scrollTo(0, document.documentElement.scrollHeight));
await page.waitForTimeout(6000);
const bottom = await page.evaluate(() => window.__spin.sample());
bottom.agreement > 0.9 ? ok(`bottom agreement ${bottom.agreement.toFixed(3)} (domains)`) : fail(`bottom agreement ${bottom.agreement}`);

const T = await page.evaluate(() => window.__spin.temperature());
Math.abs(T - 0.6) < 1e-6 ? ok('bottom temperature is the cold end') : fail(`bottom T ${T}`);

consoleErrors.length === 0 ? ok('no console errors') : fail(`console errors: ${consoleErrors.join(' | ')}`);

await browser.close();
if (process.exitCode) process.exit(process.exitCode);
console.log('spin QA passed');
```
